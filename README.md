# Slozhno-sosredotochitsya-fd


## Description
A one-page website that reflects the reasons why it is difficult for us to concentrate. The website provides information about the causes of decreased concentration, as well as ways to increase it. 
The website is adapted for various devices and has two themes: light and dark.

## Installation
